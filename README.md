# GTA Online PC Accounts — Storefront

Static storefront page for PC-only GTA Online account packages, with a Cash App checkout flow.

## Contents

- `index.html` — the entire site: markup, styles and the small package-selection script. No build step, no dependencies.

## Publishing with GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**. The page will then serve at `https://nolbert4-dev.github.io/gta-online-pc-accounts/`.
